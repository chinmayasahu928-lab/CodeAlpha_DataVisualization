# CodeAlpha_DataVisualization
# CodeAlpha Task 3 – Data Visualization

## 📌 Objective

Create meaningful **charts and visualizations** from the 1,000 Books dataset analyzed in Task 2.

## 🛠️ Tools Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Seaborn

## 📂 Dataset

The dataset contains:

* Book Title
* Price
* Rating
* Availability
* Book URL

## 📊 Visualizations Created

* Book Price Distribution
* Book Rating Distribution
* Price vs Rating
* Top 10 Most Expensive Books
* Average Price by Rating

## 🔍 Key Insights

The visualizations help understand **book prices, ratings, price distribution, and the relationship between price and rating**.


## 🎓 Learning Outcome

Learned how to create and interpret **data visualizations using Python** and present data in a simple and understandable way.
